# 分镜表

全片 9 个镜头 / 11 个叙事节拍，共 48 秒。运镜参数与调色都在 `script/plan.json` 里，改数值即可重渲。

## 镜头 1｜分屏对照（0.0–8.0s，8.0s）

- **画面**：左右各一桌，左暖金天堂、右冷青蓝地狱，中间 6px 暗缝。四对角色分坐长桌两侧，各握两米长筷。
- **运镜**：**完全静止**（`kind: "static"`）。这一镜不推不摇——早期版本在这里做慢推，8 秒的慢速 zoompan 会因整像素舍入产生轻微抖动，观感发晕，所以改成静止。
- **字幕**：两段，4.3 秒处换气。
- **素材**：`01b_heaven_portrait` + `02b_hell_portrait` 由 `build.mjs` 现场 hstack 合成，不单独存图。

## 镜头 2｜筷子特写（8.0–11.5s，3.5s）

- **画面**：中线交叉的两双长筷，左暖右冷，浅景深只留交叉处清晰。
- **运镜**：1.0 → 1.05 极缓推进。
- **字幕**：`筷子——特别长。`（7 字 / 2.8 秒，全片最慢）
- **素材**：`10c_chopstick_cross`

## 镜头 3｜送不进嘴（11.5–16.5s，5.0s）

- **画面**：小恶魔双手捏住筷子最末端，手臂伸直，食物停在嘴前一大截。
- **运镜**：1.0 → 1.04，几乎不动，让观众自己看清那个距离。
- **字幕**：`长到怎么伸，都送不进自己嘴里。`
- **素材**：`03d_closeup_fail`（这一张迭代过三版，见 production-notes）

## 镜头 4｜天堂互喂（16.5–22.0s，5.5s）

- **画面**：棕发天使夹菜越过整张桌，送到金卷发天使嘴边。
- **运镜**：1.0 → 1.08 缓推 + 柔光 Bloom。
- **字幕**：`天堂里，每个人夹起菜，都先递给对面的人。`

## 镜头 5｜吃饱了（22.0–27.0s，5.0s）

- **画面**：盘子见底、骨头堆成小山，四个天使靠回椅背笑。
- **运镜**：1.07 → 1.0 **缓拉**（和前面所有推镜方向相反，暗示"松下来"）。
- **字幕**：`大家都能吃饱吃好，笑得心满意足。`

## 镜头 6｜攥紧筷子（27.0–31.0s，4.0s）

- **画面**：四个怪物身体前倾、指节发白地攥着筷子，桌上饭菜完好没人动。
- **运镜**：1.0 → 1.09 + 轻微手持抖动。**调色在此切到冷蓝**，是冷暖分界点。
- **字幕**：`而地狱里，人人都把筷子攥得紧紧的。`

## 镜头 7｜抢（31.0–35.0s，4.0s）

- **画面**：筷子在空中交叉戳撞，盘子翻倒，食物飞溅。
- **运镜**：1.05 → 1.16 + 横向摇 + 手持抖动，全片最快的一镜。
- **字幕**：`你抢我的，我抢你的。`

## 镜头 8｜饿殍（35.0–40.0s，5.0s）

- **画面**：怪物瘦得脱形、眼神空洞，桌上只剩空盘冷渣。
- **运镜**：1.0 → 1.05 缓推，速度重新放慢，形成"抢完之后死寂"的落差。
- **字幕**：`抢到最后，谁也没吃上一口。`

## 镜头 9｜点题（40.0–48.0s，8.0s）

- **画面**：纯黑底，一双长筷斜放，一道极窄暖金边缘光。
- **运镜**：前 2.5 秒从 1.0 推到 1.06，然后**定格**（`freeze: 2.5`）；最后 1.3 秒淡黑。
- **字幕**：三行依次出现，间隔 2 秒：
  ```
  40.0  所以                     48px
  42.0  所谓天堂和地狱——         56px
  44.0  只隔着一双，指向谁的筷子。  74px
  ```
- **声音**：40 秒起抽掉冷暖两段，只剩一根长音缓慢衰减，46 秒开始 2.2 秒淡出。

## 节奏设计

- 前 8 秒不动 → 3.5 秒极缓 → 5 秒几乎不动：**用"静"把观众按在座位上**。
- 27–35 秒连续两次推近 + 抖动：**唯一"快"的地方**。
- 35 秒重新放慢，40 秒彻底停住：快慢落差就是情绪落差。
- 全片字幕 12 块，块与块之间都留了 0.4–1.4 秒的空档。
