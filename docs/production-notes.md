# 制作笔记

记录这支片子从 0 到 1 的过程，包括走过的弯路——对复现或做同类项目的人应该有用。

## 0. 环境现实

开工前先摸清了这台机器上有什么：

| 能力 | 状态 | 影响 |
|---|---|---|
| 生图模型 | ✅ 可用（OpenAI 兼容 `/images/generations` 与 `/images/edits`） | 关键帧与角色一致性靠它 |
| 视频模型 | ❌ 供应商目录为空 | 放弃"逐镜头 AI 生视频"，改走静帧 + 程序化运镜 |
| 视觉模型 | ✅ 可用（chat/completions 带图） | 当成"眼睛"来验收每一张图 |
| TTS | ❌ SAPI 语音目录异常、接口无 `/audio/speech` | 最终无配音，改字幕 + 配乐 |

关键判断：**没有视频模型不代表做不了片子**，但要把"动"的活儿全部交给 ffmpeg——推、拉、摇、抖、交叉溶解、定格。这个约束反而逼出了更可控的节奏。

## 1. 先解决"我看不见"

我读不了图，所以第一步是把 4 张锚点图喂给视觉模型，让它们变成**结构化文字**：画风、角色清单（发色 / 服饰 / 头身比 / 表情）、色板（带十六进制）、构图。

这份描述后来成了所有提示词的地基。尤其是「2.5 头身」「圆脸珊瑚红腮红」「白袍金色光环」这类细节，不写进去，图生图就会跑偏。

## 2. 角色一致性：靠参考图，不靠形容词

第一版只用文字描述角色，结果四张图里出现了四套不同的画风。改成**图生图**（`/images/edits` 带锚点图）之后，发色、服装、比例立刻稳住了。

经验：**提示词负责"这张图讲什么"，参考图负责"长什么样"**，两者不要混为一谈。

## 3. 镜头 3 迭代了三次

「筷子太长，送不进嘴」这个笑点，前三版都没说清楚：

- **v1**：角色握着筷子，食物悬在嘴前。观众会想"把筷子收回来不就行了"。
- **v2**：加了"另一端抵住石壁当支点"。支点看不清，反而更糊涂。
- **v3**（采用）：把**嘴和手放在画面同一侧**，筷子从手边一直伸到画面另一角的食物——"食物到嘴的距离 ≈ 整根筷子长度"这个几何关系一眼成立。

教训：**单帧表达因果很难**，能靠构图解决的，别靠形容词。

## 4. 两个被裁掉的坑

- **食物出画**：镜头 3 的第一版，16:9 裁切把右上角的食物切掉了一半，笑点直接没了。解决办法是在提示词里写死安全区（"距上边缘和右边缘至少留 10% 空白"）。
- **分屏比例**：3:2 的图硬裁成 8:9 会切掉两侧的人。最后为分屏**单独生成了两张竖幅图**（1024×1536），而不是拿横幅去裁。

## 5. 抖动：不是运镜问题，是舍入问题

第一版分屏用 8 秒慢推，观感"晕"。逐帧差分后发现不是抖动参数的问题，而是 `zoompan` 在慢速缩放时**整像素舍入**导致的细微跳动。

两个修法一起上：

1. **2 倍超采样**：先渲到 3840×2160，再降采样到 1080p，把亚像素位移"抹平"。
2. **静止镜头走另一条分支**：开场分屏干脆不推（`kind: "static"`），不经过 `zoompan`，差分实测位移 ≈ 0。

## 6. 文案改了四轮

| 轮次 | 问题 | 改法 |
|---|---|---|
| 初稿 | 说明书腔，"区别不在环境而在人心"是结论 | — |
| 二稿 | 短句口号化（"于是抢。""两个方向。"），一句接一句砸 | 加长句、减密度 |
| 三稿 | 还是"没有呼吸"，结尾太快 | 蒙太奇整段不说话，结尾给 5 秒 |
| 终稿 | 结构改成先天堂后地狱，娓娓道来 | 11 个节拍，语速压到 2.5–5 字/秒 |

最有用的两个动作：**把字幕块砍到 9 块**（原 12 块），以及**让结尾三行分三次出现**，每行之间空 2 秒。

## 7. 结尾"戛然而止"的真正原因

不是画面短，是**音乐早就衰没了**：收尾段用的是三个指数衰减的正弦，到 44 秒已经掉到 −42 dB，等于静音，画面却还挂着。

修法：收尾段加一层不衰减的 130Hz 低音垫底，最后 3 秒响度从 −41.9 dB 提到 −34.3 dB，再交给 2.2 秒淡出。现在是一条平顺的尾巴。

## 8. 声音怎么做（没有 TTS 的情况下）

配乐不是找的素材，是**用 ffmpeg 的 `aevalsrc` 现场合成的**：

- 暖段：C 大调五个正弦（130.81 / 196 / 261.63 / 329.63 / 392Hz）+ 慢速颤音 + 低通 + 回声；
- 冷段：55 / 82.5 / 110Hz 低频嗡鸣 + 滤波噪声；
- 收尾段：衰减的正弦 + 持续低音。

三段用 `acrossfade` 缝合，总长由片长反推，保证精确对齐。听起来朴素，但**完全可复现、零版权风险**。

## 9. 如果要继续做

- 接视频模型：`plan.json` 的每个 `beat` 换成图生视频片段，其余流程（字幕、配乐、拼接）不用动。
- 补配音：`script/narration.md` 里每句都在 12 字以内、标了换气点，直接念即可。
- 竖屏版：分屏镜头需要重新构图，其余镜头裁切即可。
